이후 Java · Spring 기반 연구자 포털과 Oracle PL/SQL 업무 시스템을 개발하며 REST · SOAP API 연동, 상태 · 오류 흐름 설계, 대량 데이터 처리 역량을 키웠습니다. 데이터 불일치나 외부 API 장애는 예외를 우회하기보다 로그 · 원본 데이터 · 업무 규칙을 함께 확인해 원인을 좁히고, 검증 가능한 방식으로 개선해 왔습니다.

데이터메이커에 어떤 역량을 보여줄 수 있을지 고민하며, 공개된 Synapse SDK로 개인 프로젝트도 진행했습니다. 논문 데이터를 수집 · 정제 · 청크화하고 품질 리포트를 생성하는 RAG 데이터셋 플러그인을 SDK 명세(config · Action · Storage)에 맞춰 만들며, AI 기능의 품질은 모델뿐 아니라 데이터의 신뢰도와 실행 흐름, 재사용 가능한 인터페이스에 달려 있다는 것을 배웠습니다.

AI 도구는 구현과 탐색의 생산성을 높이는 수단으로 쓰되, 확보한 시간은 결과물의 재검증과 예외 조건 점검에 씁니다. 제안된 코드도 데이터 흐름과 업무 규칙에 맞는지 직접 검토하고 고도화합니다. 이렇게 AI 활용의 속도와 결과물의 신뢰도를 함께 높이는 백엔드를 만들고 싶습니다.
